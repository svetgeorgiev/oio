# Master roadmap

## v0.1 — delivered
- [x] Vue dashboard with responsive dark theme
- [x] Python standard-library localhost API and SQLite persistence
- [x] Idempotent synthetic fixture ingestion
- [x] Exact-text short-window coordination candidate detection
- [x] Evidence links and human-review status placeholder
- [x] Automated unit tests

## v0.2 — next, before real data
- [ ] Source permission review and data protection impact assessment
- [ ] Schema migrations, data retention/deletion and audit logs
- [ ] Authentication, authorization, request limits, abuse prevention
- [ ] Case workflow: reviewer notes, competing explanations, dismissal, appeal
- [ ] Dataset provenance, reproducibility, confidence calibration, benchmarks
- [ ] Timestamp clustering and network visualization, with false-positive tests

## v0.3 — controlled pilot
- [ ] One approved public-data source adapter, with bounded ingestion
- [ ] Background job queue, backoff, monitoring, operational alerts
- [ ] Analyst dashboard with time filters and network exploration
- [ ] Independent review of methodology and privacy safeguards

## v1.0 — public transparency portal (only after governance review)
- [ ] Campaign-level reviewed findings, evidence summaries, uncertainty
- [ ] Corrections/appeals and publication approval controls
- [ ] Public methodology, evaluation metrics, transparent change log
- [ ] Moderation and legal escalation pathways

## Out of scope
Private account attribution, covert surveillance, mass account blacklists, automated public accusations, server intrusion, or bypassing platform access controls.
